# Gabriel F. Costa — Academic Portfolio

Static site reconstructed to match the saved ChatGPT Sites reference, using its recovered HTML structure and separately implemented CSS and JavaScript animations. It is a close recreation, not an export of the unavailable original site source.

## Deploy to GitHub Pages
Upload all files and the `assets` directory to the root of the `main` branch of `gabrielxcosta/gabrielxcosta.github.io`. Settings → Pages → Deploy from branch → main → /(root).

- `index.html` and `about.html`: reference-style About page with animated atom and dynamic stochastic-block network.
- `resume.html`, `publications.html`, `projects.html`, `research.html`: standalone pages.
- `assets/site.css`: layout, palette and responsive styles.
- `assets/site.js`: localization, scroll reveal and project icons.
- `assets/atom.js`: animated atom.
- `assets/network.js`: living network.

The source image and CV are included. Javascript-only graphics need a browser with Canvas enabled.
