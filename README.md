# Gabriel F. Costa — Academic Portfolio

Static bilingual (English / Portuguese) personal website for GitHub Pages.

## Publish manually

1. Extract this ZIP.
2. In `gabrielxcosta/gabrielxcosta.github.io`, upload **the contents** of this folder to the root of the `main` branch. Replace previous files when prompted.
3. Go to Settings → Pages → Deploy from a branch → `main` → `/(root)` → Save.
4. Visit https://gabrielxcosta.github.io/.

Pages: Home, About, Research, Publications, Projects, Resume. No build step or external JavaScript libraries are required. Google Fonts is optional; system fallbacks are included.

Important: Google Scholar is currently a publication-search link rather than a verified profile URL. Replace it in `about.html` when the exact URL is available. Public location is city-level only.

Interactive graphics are in `assets/site.js`. The stochastic-block network runs on the home page, and the animated atom is on the About page. Both honor reduced-motion settings.
